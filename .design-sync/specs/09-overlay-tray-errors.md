# 設計稿 09 · 大螢幕顯示層與周邊畫面

來源：`09 大螢幕顯示層與周邊.dc.html`

## A. 顯示層 child.html（1920×1080，透明、點擊穿透）

### D1 · 入場 QR
- 深色漸層底 `linear-gradient(160deg,#0a1628,#02060f)`，水平置中，QR 與文字區 gap 64px
- QR：260×260 白卡、圓角 24px、內距 20px
- 右側直排：wordmark（60px 高）／「掃 QR 或打開」34px + 網址 pill（等寬字、`rgba(255,255,255,.1)` 底、圓角 12px）／「打字，就會飛到這個螢幕上」22px slate-400／「● 已就緒 · 等待第一則彈幕」18px 綠、色點帶 glow
- 右下角 14px 半透明提示：「主持人：按 ⌘⇧Q 或系統匣可關閉此畫面」
- **移除**原本的「DESKTOP READY · 等待中」chip 與掃描線背景

### D2 · 顯示中
- **畫面上只有彈幕，沒有任何 HUD**。彈幕計數只出現在桌面端控制視窗與 Admin
- 彈幕陰影固定 `0 0 4px #000, 0 2px 8px rgba(0,0,0,.7)`——白字疊白色簡報也讀得到
- 名字前綴 18px slate-200，本文 36px 700

### D3 · 投票結果推到大螢幕（新增）
- 主持人按「推到大螢幕」，**15 秒後自動收起**
- 置中卡片 560px、`rgba(2,6,15,.88)` + `backdrop-filter: blur(12px)`、圓角 24px、內距 32/36
- 內容：「投票結果 · 31 票」16px slate-400 → 題目 30px 700 → 長條列（選項 96px 標籤／30px 高進度條／右側百分比 tabular-nums）
- 進度條顏色依名次遞減透明度：`#38bdf8` → `.6` → `.35`

## B. 系統匣選單（9 項 → 6 項）

現況（main.js）：狀態列、顯示 Desktop、Desktop 視窗數、入場 QR、伺服器＋更改連線、開啟控制視窗、偏好設定、關於、結束。

新版結構：

```

─────────────
關閉顯示層                    ⌘⇧D   ← 主要動作永遠第一項、帶快速鍵、highlight
顯示入場 QR                   ⌘⇧Q
清空畫面
─────────────
開啟控制視窗…
設定…                          ⌘,   ← 「更改連線」「關於」收進這裡
─────────────
結束 Danmu Fire                ⌘Q
```

- 未開啟時：狀態行變灰「未開啟 · 伺服器已連線」，第一項變「開啟顯示層」，「顯示入場 QR」變 disabled 灰字
- Windows 快速鍵寫 `Ctrl+Shift+D`，無 ⌘, 一項
- **匣圖示右下角小色點同步狀態**，不點開也看得到

## C. 觀眾端投票「已投票」狀態（V1）

- 已選項：`rgba(2,132,199,.1)` 底 + 2px 主色框 + 22px ✓ 圓標，文字 `#0369a1` 600
- 未選項：淺灰底、次要文字色、無框
- 底部說明：「已收到你的一票。結果會在主持人公布後顯示在大螢幕。」

## D. 錯誤頁（server/templates/errors）

共同結構：app icon 64px（opacity .5）→ 標題 → 兩行說明「發生什麼、你可以做什麼」→ 主按鈕一顆 → **技術訊息移到頁腳小字**

- **404**：「找不到這個頁面」／「網址可能打錯了，或活動已經結束。試著重新掃描現場的 QR code。」／按鈕「回到首頁」／頁腳「錯誤代碼 404」
- **500**：「伺服器暫時出了點問題」／「我們已經記錄下來了。請稍等幾秒再重新整理；如果一直發生，請告訴現場工作人員。」／按鈕「重新整理」（主）＋「回到首頁」（次）／頁腳等寬「500 · 時間戳 · ref 8f3a2c」
