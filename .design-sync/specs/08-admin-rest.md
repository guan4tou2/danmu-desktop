# 設計稿 08 · Admin 其餘頁面與流程（第三輪）

來源：`08 Admin 其餘頁面與流程.dc.html`。全部套 07 模板（1024 寬、圖示側欄）。

## 合併規則（IA）

- 原「Emoji 庫／Sticker 包／字型管理／聲音庫」四頁 → **「素材」一頁的分段控制**
- 原「Webhook／插件／API Token／定時發送」→ **「擴充」一頁的分段控制**
- 原「場次／搜尋／操作日誌／重播」→ **「紀錄與匯出」一頁**
- 首次設定精靈與導覽 → **全螢幕流程**

## T1 · 主題（原「風格主題包」）

- 頁首右側「新主題」
- 說明：「決定所有彈幕的字型、描邊與陰影。一次只能套用一個主題，觀眾選的顏色與效果會疊在主題上。」
- 4 張主題卡（標準／霓虹／復古／電影），每張含「彈幕範例」預覽；使用中的顯示「使用中」，其餘顯示「套用」
- 下方「標準 · 細部設定」群組：
  - 字型（下拉：Noto Sans TC 粗體）
  - 描邊（分段：無／細／粗）
  - 陰影（分段：無／柔和／強烈）
  - 觀眾預設顏色
  - 預覽條（小明 講得好！+1）

## T2 · 素材（四合一）

- 分段控制：`表情 12` / `貼圖 3 包` / `字型 2` / `音效 4`；右側「上傳」
- 說明：「觀眾在訊息裡輸入 `:名稱:` 就會變成表情。PNG／GIF，建議 64×64。」
- 拖放區：「把圖片拖到這裡上傳，或**選擇檔案**」
- 表情格狀卡：emoji ／ `:fire:` ／「用過 128 次」或「尚未使用」
- 註記：「點卡片可改名或刪除。「字型」分段可上傳 .woff2／.ttf 並自動子集化；「音效」分段含關鍵字觸發規則。」

## W1 · 小工具（Desktop Widgets）

- 頁首右側「新增小工具」
- 說明：「常駐在大螢幕上的計分板、跑馬燈或文字標籤。拖預覽裡的方塊可改位置。」
- 三列（圖示＋名稱＋摘要＋`›`）：計分板「資工 12 · 電機 9 · 右上」／跑馬燈「「歡迎參加 2026 迎新晚會」· 底部」／文字標籤「「#問答時間」· 左上」
- 右側「大螢幕預覽」：實際渲染計分板、底部跑馬燈、已關閉的標籤（灰）

## H1 · 紀錄與匯出（四合一）

- 分段：`場次` / `搜尋訊息` / `操作紀錄`
- 說明：「每次開啟顯示層算一場。可匯出 CSV（試算表）、JSON（完整）或 SRT（字幕，直接套到影片）。」
- 表格欄：場次／訊息／觀眾／時長／`匯出 ›`
- 匯出面板（右側或抽屜）「匯出「校慶開幕」」：
  - 格式分段：CSV 試算表／JSON 完整／SRT 字幕
  - 開關「包含觀眾 IP 與裝置識別」＋警語「屬個人資料，分享前請確認」
  - 兩顆按鈕：「重播這場」（次）／「下載 CSV」（主）

## X1 · 擴充（四合一）

- 分段：`Webhook 2` / `插件 1` / `API 金鑰 1` / `定時發送`；右側「新增 Webhook」
- 說明：「給 IT 人員的區域。把彈幕即時轉發到 Discord／Slack，或讓外部服務發彈幕進來。」
- Webhook 列：名稱／URL 截斷＋觸發事件／「上次 14:32 · 200」／`›`
  - 失敗狀態：「連續 3 次失敗（連線逾時）· 已暫停」＋「重試」按鈕
- 「最近送出」表：時間／狀態碼（200 / timeout）／事件 → 目標／耗時

## S1 · 系統（總覽與關於）

- 頁首右側狀態 chip「運作正常」
- 說明：「伺服器狀態、語言、備份、安全、擴充的入口。**原側欄 TELEMETRY 移到這裡**。」
- KPI 4 格：運行時間 `3 天 4 時`／已連線 `39`（副標「1 顯示層 · 37 觀眾 · 1 後台」）／記憶體 `41%`／版本 `5.3.1`（副標「最新」）
- 群組列：
  - 公開網址 `https://danmu.acme.co` ＋「複製」「QR」
  - 後台語言（下拉 繁體中文）
  - 後台深淺色（分段 跟隨系統／淺／深）
  - 備份與還原 → 「上次備份 昨天 23:00 ›」
  - 安全 → 「連線密碼已啟用 ›」
  - 擴充 → 「1 個 Webhook 失敗 ›」
  - 關於 Danmu Fire → 「開源 · GitHub · 授權 ›」

## F1 · 首次設定精靈 `#/setup`（全螢幕 4 步）

- 頁首：「首次設定」＋「第 2 步，共 4 步 · **略過，稍後再說**」
- 步驟 2 內容：標題「選一個起手主題」／說明「決定彈幕的字型、描邊與陰影。之後隨時可以在「主題」細修。」
- 4 張主題卡帶一行定位說明：
  - 標準 — 白色彈幕，適合大多數畫面
  - 霓虹 — 高對比發光，適合深色舞台
  - 復古 — 暖色像素感，適合活動主視覺
  - 電影 — 低飽和金色字幕感，適合論壇
- 底部：`‹ 上一步` ／ 「繼續」主按鈕
- 進度文字：`1 伺服器網址 · **2 主題** · 3 審核基本防線 · 4 完成`

## N1 · 通知中心 `#/notifications` → **改為右上彈出面板**

- 由頂欄鈴鐺（帶數字 badge）開啟，不再是獨立路由頁
- 面板標題「通知」＋「全部標為已讀」
- 每則：文字／來源與時間（`審核 · 14:32`）／可選行動按鈕（「查看」「重試」）
- 範例：
  - 「3 則訊息因「加line」被擋下」— 審核 · 14:32 — 查看
  - 「Webhook「內部紀錄伺服器」已暫停」— 擴充 · 14:31 · 連續 3 次逾時 — 重試
  - 「裝置 a3f9c2 一分鐘內發了 14 則，已暫時限速」— 審核 · 14:20
  - 「顯示層「主場筆電」已連線」— 13:08
