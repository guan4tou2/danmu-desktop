# 設計稿 16 · 觀眾頁與顯示層補充

來源：`16 觀眾頁與顯示層補充.dc.html`

## VL1 · 手機橫向 844×390

- **不鎖方向、不出提示要人轉回來**
- 左欄固定 300px：字標／狀態 chip／預覽（撐滿高度）／樣式列 44px
- 右欄：上半「最近送出」清單、下半輸入框＋48px 送出鍵貼底

## VK1 · 鍵盤彈出

- 用 `interactive-widget=resizes-content`（viewport meta）讓送出列跟著鍵盤
- **預覽縮到 72px、樣式列收起**，讓輸入框緊貼鍵盤
- 鍵盤上方一列常用 emoji ＋短句：👏 🔥 😂 ❤️ ／ `+1` `666` `講得好`（36px 高）
- 輸入框聚焦：1px 主色框 ＋ `0 0 0 3px rgba(2,132,199,.2)`
- 底下一行：「Enter 送出」／「4/100」

## VN1 · 首次進入暱稱提示

- **內嵌卡片不是 modal**，右上有 `×` 可關；填過就不再出現
- 40px 圓形頭像「匿」／標題「想留個名字嗎？」／說明「大螢幕上會顯示在彈幕前面。不填就以「匿名」送出，隨時可改。」
- 一列：輸入框「暱稱（最多 12 字）」＋「好」主按鈕
- 預覽區此時顯示「匿名 你好！」

## VP1 · iPad 橫向 1180×820

- **≥768 直接用桌面版面**；樣式改為**右側常駐面板 360px**，不用抽層
- 左側：頁首（字標＋副標＋狀態 chip＋主題兩段切換）／預覽區（圓角 20px、大螢幕比例、撐滿）／輸入列 52px ＋「發送」pill
- 右側面板直排群組：暱稱（44px 列，右側「改」）／顏色（6 欄 grid、`aspect-ratio:1`）／大小（分段 小中大）／效果（pill：無・發光・彈跳・彩虹・抖動）／位置（分段 飄過・頂端・底部）

## OS1 · 投影安全區

- **預設內縮 5%**（overscan）；投影機常裁掉邊 2–5%
- 所有軌道（飄過／頂端固定／底部固定）與投票卡、入場 QR **都以安全區為邊界**，不貼螢幕邊
- Admin › 顯示層 › 安全區：`0% / 5%（預設）/ 8%`

## OS2 · 淺色簡報上的描邊規則

- 顯示層**每 2 秒取樣背景平均亮度**，不用主持人手動切
- 亮度 **> 60% 視為淺底** → 淺色彈幕加 `1.5px` 深描邊、深色彈幕加白光暈
- 亮度 **≤ 60%** 維持原本陰影
- 用 `-webkit-text-stroke: 1.5px rgba(15,23,42,.9)` ＋ **`paint-order: stroke fill`**（保住字形不變胖）
- 深字光暈：`text-shadow: 0 0 2px #fff, 0 0 8px rgba(255,255,255,.9)`
- Admin › 顯示層可鎖定「總是描邊」

## OS3 · 多題投票（大螢幕）

- **一次只顯示一題**；卡片貼安全區底部（`left/right:5%; bottom:8%`）
- 卡頭：`投票 2 / 3` chip ／ 題目 30px 700 ／ 右上倒數 22px `tabular-nums` 琥珀色
- 選項 2×2 grid：`A` 灰色字母前綴＋選項名 22px 700 ／ 右側百分比 ／ 14px 進度條
- **結果條同色**（`#38bdf8`），不分彩虹，**最高票不另外標色**——讓數字說話
- 卡底：「已投 **29** / 37 人 · 在手機上點選項投票」／右側題目進度點（已完成／當前／未開始）
