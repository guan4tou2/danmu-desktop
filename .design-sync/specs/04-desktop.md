# 04 桌面端示範 · Electron 主視窗

## 核心：從「三分區側欄 800×900」→「單頁 560×440」

視窗尺寸：標準 560×440、精簡 360×200（<420 寬自動切換）
跟隨系統深淺色；macOS 原生標題列、Windows 系統框

## 六個狀態
- S1 首次啟動精靈：只問一個欄位（伺服器位址）＋「稍後設定 / 測試並繼續」
- S2 日常未開啟（預設進入）：顯示層卡片 + 開啟主按鈕 + 設定群組（顯示在 / 伺服器）
- S3 已開啟：卡片綠框、「顯示中 · Display 2 · 已顯示 128 則」、關閉鈕淡紅
- S4 連線失敗：明確橫幅（原因＋已重試次數＋「重試 / 變更位址」）
- S5 多螢幕選擇：popover，含「所有螢幕同步顯示」
- S6 有更新：一條可關閉橫幅 ＋ ⚙ 小紅點（不阻斷）

## P1 設定面板（⚙ 開啟，取代「連線」與「關於」兩分頁）
- 伺服器：位址 / 連線密碼（未設定 · 伺服器要求時才需要）/ 測試連線
- 一般：登入時自動開啟顯示層 / 啟動動畫 / 快速鍵 ⌘⇧D
- 關於：版本 + 已是最新 + 檢查更新 + GitHub

## 對照表（要改什麼）
| 面向 | 現況 | 目標 |
|---|---|---|
| 結構 | 三分區側欄 | 單頁；連線與關於收進 ⚙ |
| 主要動作 | 「▶ 開啟 Desktop」小按鈕 | 卡片中最大主按鈕；開啟後轉淡紅「關閉」 |
| 狀態 | 標題列 DISCONNECTED、側欄 UP TO DATE、卡片 LAST TEST 三處 | 只留卡片一處「色點＋文字」 |
| 文字 | SERVER · CONFIGURE 等雙語 | 單語白話；Token→連線密碼；Desktop→顯示層 |
| 字體 | Bebas+Noto+JetBrains 三族、11px 全大寫 | 系統字體單族、最小 12px、正文 15px |
| 尺寸 | 800×900 | 560×440 / 360×200；點擊目標 ≥32、主按鈕 40 |
| 錯誤 | 只在 chip 變紅 | 明確橫幅：原因、重試次數、兩個動作 |
| 更新 | 獨立卡片＋標題列徽章 | 可關閉橫幅＋⚙ 小紅點 |
